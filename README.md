# 개발 포트폴리오

서버 개발, AI Agent 구현, 클라우드 인프라 구축·운영 경험을 프로젝트별로 정리했습니다. 각 프로젝트 페이지에서 주요 구현 내용과 역할별 소스 코드 저장소를 확인할 수 있습니다.

| 프로젝트 | 주요 내용 | 상세 소개 및 저장소 목록 |
| --- | --- | --- |
| AI Agent 분석 플랫폼 | Python·FastAPI, LangChain, RAG, 질의 분석·도구 선택, 멀티턴 대화 | [AI Agent 프로젝트 보기](projects/ai-agent.md) |
| 체험단 플랫폼 | Spring Boot·Kotlin MSA, Cognito 인증, S3 이미지 저장, EKS·GitOps 배포 | [체험단 플랫폼 프로젝트 보기](projects/marketing-platform.md) |
| x-lite 플랫폼 | Java·Kotlin 서버 개발, Kafka 알림, 로그·메트릭 모니터링, CI/CD | [x-lite 프로젝트 보기](projects/x-lite.md) |

## 기술과 경험

- **서버 개발:** Python, FastAPI, Java, Kotlin, Spring Boot
- **AI Agent:** LangChain, RAG, ChromaDB, 질의 구조화와 도구 선택, 세션 기반 대화 이력
- **인프라 및 배포:** AWS EKS, Docker, Kubernetes, GitHub Actions, ArgoCD, Helm
- **데이터 및 운영:** MySQL, S3, Kafka, ELK, Prometheus, Grafana

## 프로젝트를 보는 방법

프로젝트 이름을 선택하면 목적, 개발 범위, 구현 내용, 관련 저장소 목록으로 이동합니다. 서비스별로 나뉜 저장소를 함께 읽을 수 있도록 이 저장소를 안내 페이지로 구성했습니다.
